# 📦 Sistema de Gestión de Almacenes

¡Bienvenido a mi proyecto! Este es un sistema moderno desarrollado con **Tauri** y **Vite** para controlar inventarios y almacenes de forma eficiente.

## 🚀 Tecnologías utilizadas
* **Frontend:** HTML, CSS, JavaScript / Vite
* **Escritorio:** Tauri (Rust)
* **Analítica de Datos:** Conceptos de Data Warehousing

## 🛠️ Características principales
* Registro de productos en tiempo real.
* Interfaz rápida y ligera para computadoras.
* Control de stock automatizado.

## 💻 Cómo ejecutar el proyecto
1. Instala las dependencias con `npm install`
2. Corre el proyecto en modo desarrollo con `npm run tauri dev`
